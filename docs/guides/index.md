# Guides

Task-focused how-tos that span more than one feature. Each guide walks a single end-to-end job using the platform primitives — start here when you know *what* you want to build but not *which* pieces fit together.

-   [Wire a new HTTP controller](http-controller.md) — expose a custom REST endpoint backed by the command bus, with auth and tenant context.
-   [Run work on a schedule or in the background](scheduled-jobs.md) — register cron jobs, enqueue ad-hoc background work, and report progress.

For a guided build from scratch, start with the [Tutorial](../tutorial/00-installation.md). For a single feature's surface, see the [Feature catalog](../features/index.md).
