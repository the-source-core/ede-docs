Section 01

01What the Control Tower does & how to read this guide

The Control Tower turns a ready_for_execution shipment into a live, governed logistics.execution. It reads physical truth (equipment movements, gate events, cut-offs) and writes operational decisions (tasks, legs, exceptions, completion), then projects a customer-facing execution_status back onto logistics.shipment via @api.extend_model (SOE-16) — the shipments source file is never edited.

The state machines you will observe

The execution carries a governed lifecycle; the shipment carries a derived operational projection recomputed by logistics.execution.derive_status from execution + leg state. Watch both, plus the leg and cut-off machines.

execution   : draft → activated → in_execution → completed  |  cancelled
ship.exec   : not_activated → activated → in_execution → on_hold → completed  (SOE-16, derived)
leg       : pending → in_progress → completed  |  skipped
cut-off   : pending → at_risk → met  |  missed  |  waived

The BR-01 activation gate

  • Shipment must be ready_for_execution
  • An owner is set (ops.execution.require_owner_before_activation)
  • No duplicate active execution for the shipment
  • No unresolved critical exception (ops.execution.block_on_critical_exception)

Auto-opened exceptions (SOE-13)

  • cutoff_miss · critical — on a missed cut-off
  • cargo_issue · high — on pickup/delivery damage
  • vendor_issue · medium — on a provider decline
  • Eight categories total; severity ladder low→medium→high→critical

The completion blockers (BR-09/10)

What blocks completion

  • mandatory task(s) open — a mandatory task not done
  • mandatory milestone(s) open — not reached
  • unresolved critical exception — not resolved/closed
  • POD missing where delivery in scope — no pod_doc_id

Carry-forward semantics (SOE-17)

  • Not a separate command — the carry_forward flag on complete
  • Gated by ops.completion.allow_carry_forward
  • Completion row stamped carry_forward, note kept
  • Blockers still returned in the result for audit
